# 全站视觉统一重设计

## 设计方向

**核心参考**：Google 搜索首页的极简空间感 + Apple 产品页的字体层次和呼吸感
- 白底为主，极少量浅灰辅助区分层次
- 大字号标题（40-56px）、充裕留白、字重对比强烈
- 品牌色收敛为1个主色（建议保留深蓝 #1e40af 或换为更沉稳的 #111827 纯黑+蓝点缀）
- 无圆角卡片满天飞，用留白和线条建立结构

---

## Task 1：首页重设计（index.html）

**现状**：深色背景 #0a0f1a，紧凑布局，偏工具/极客感
**目标**：白底、大气、正式，像一个值得信任的官方工具

### 视觉改动
- 背景：`#0a0f1a` 深色 → `#ffffff` 纯白（或 #fafafa 极浅灰）
- 品牌标题：保持 LAOWAITOWN，字号放大到 40-48px，字重 800，纯黑色
- 搜索引导文案：字号 18-20px，灰色 #6b7280，下方留 40px+ 空白
- 搜索框：白底 + 1px 浅灰边框 + 轻微阴影，聚焦时蓝色边框
- Tab 栏（Country / Purpose）：简化为底线式，无背景色
- 工具区：每个工具卡片用极细边框 + 大标题 + 小描述，不要图标
- 政策结果面板：白底卡片 + 细边框，绿点/红点保留但缩小

### 字体系统
- 标题：Inter 或 system-ui，-0.03em 字距，800 字重
- 正文：16-17px，400字重，行高 1.6-1.7
- 辅助文字：13-14px，#9ca3af 灰色

### 布局
- 保持居中单栏，max-width 从 560px 放宽到 640px
- Hero 区顶部留白 80-120px（Apple 式呼吸感）
- 工具区改为 2 列网格（桌面端），移动端 1 列

## Task 2：统一子页面模板

### 模板 A — 政策/指南详情页（16个核心页 + 5个生活页 = 21页）

**用途**：visa-free-entry、240h-transit、pay-in-china 等深度内容页

**结构**（从上到下）：
1. 顶栏导航（白底粘性，logo左 + 链接中 + 暗色切换右）
2. 面包屑（轻灰小字）
3. 文章标题区（大标题 36-42px + 政策状态标签 + 更新日期）
4. 正文内容区（max-width 720px 居中，文档式排版）
5. 信源 + 免责声明
6. 相关文章推荐（2-3个卡片）
7. Footer

**去掉**：
- vm-hero 大区块（太重了）
- vm-assistant-card 右侧卡片（对详情页来说是干扰）
- vm-trust-strip（信息移入正文或 footer）

**保留**：
- 左侧目录导航（桌面端，移动端隐藏）
- 右侧 TOC 目录（桌面端）
- FAQ 折叠区
- 反馈按钮

### 模板 B — SEO 着陆页（10国家页 + 6城市页 + 5路线页 = 21页）

**用途**：搜索引擎着陆，快速给答案，引导进入首页工具

**结构**（极简，快速回答）：
1. 顶栏导航（同模板A）
2. 标题区（大标题 + 一句话答案）
3. Quick Answer 蓝色高亮框（3-5行关键信息）
4. 正文详情（精简，300-500字）
5. CTA 按钮区（"Check your eligibility on homepage" 引导回首页）
6. FAQ（2-3个常见问题，对 Google 结构化数据很重要）
7. 相关页面链接
8. Footer

**设计要点**：
- 无侧栏、无 TOC（内容短不需要）
- Quick Answer 框突出显示（Google Featured Snippet 优化）
- 页面整体控制在 1-2 屏内，快进快出
- 保留完整 JSON-LD / OG meta / canonical（SEO 基础）

## Task 3：统一 CSS 架构

**现状**：page.css (614行) + visa-modern.css + 首页内联样式，三套并存

**目标**：合并为 1 个 `site.css`

### 新 CSS 结构
```
site.css
├── Design Tokens（颜色、字体、间距变量）
├── Reset + Base（body、链接、列表）
├── Navigation（顶栏 + 面包屑）
├── Layout（.article-layout 单栏 / .with-sidebar 三栏）
├── Typography（h1-h4、p、ul、blockquote）
├── Components（Quick Answer框、FAQ、表格、卡片、CTA、Status Pill）
├── Footer
└── Responsive（768px / 1100px 断点）
```

- 删除 `page.css` 和 `visa-modern.css`
- 首页内联样式抽出为 `home.css`（仅首页专用）
- `site.css` 全站通用，控制在 400-500 行

## 执行顺序建议

1. **先做首页**：改配色+布局+字体，确认你满意整体调性
2. **再做 site.css**：基于首页确定的 tokens 编写统一样式表
3. **改造模板 A**：选 1 个核心政策页（如 visa-free-entry）做样板
4. **改造模板 B**：选 1 个 SEO 页（如 china-visa-free-entry-for-us-citizens）做样板
5. **批量应用**：确认 2 个样板后，批量更新其余 40+ 页
6. **清理**：删除 page.css、visa-modern.css，更新 build 脚本

每步做完给你审阅确认，再进入下一步。
